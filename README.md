# Reports

Static reports published from this fork's `gh-pages` branch. This branch shares no history with
`main`; it exists only to host these pages and must not be merged into the code branches.

Both are measured against upstream `origin/main` (not this fork's `main`), so no local change can
flatter the result, and against the printed-card data of five independent sources.

- [`reports/card-data/`](https://ploober.github.io/twinleafgg/reports/card-data/)
  — cards whose mechanical printed data (HP, retreat, types, Weakness, Resistance, stage,
  evolvesFrom, category) disagrees with the printed card.
- [`reports/reprint-inheritance/`](https://ploober.github.io/twinleafgg/reports/reprint-inheritance/)
  — cards that inherit their printed data from a printing of a *different* card.
